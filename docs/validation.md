# 个人版数据库结构验证

验证环境：Node.js v24.22.1，内置SQLite 3.53.4。在全新内存数据库中按序加载54张STRICT表，完成224项检查。

没有连接Cloudflare或生产数据库，没有部署应用、修改DNS或实际收发邮件。当前验证为SQLite语法、关系约束与本地事务行为，不能视为D1云端、Worker绑定或实际API/MCP验收。

## 执行方式

支持node:sqlite的Node.js 24，无需npm或外部数据库依赖。

```sh
node scripts/validate-schema.mjs
node scripts/validate-schema.mjs --dictionary
```

[验证脚本](../scripts/validate-schema.mjs)按序加载0001至0019有序迁移，最新为[批次完成与异常通知迁移](../migrations/0019_retry_batch_notifications.sql)，检查合并内容与[快照](schema.sql)一致。--dictionary从实际SQLite元数据重建[快照](schema.sql)、[字段字典](database.md)并更新本记录。每次使用内存数据库，不保留测试数据。

## 验证边界

此脚本只验证SQLite结构与事务，不是多Worker并发压测或完整权限验收。应用另有本地workerd测试覆盖D1失败补账、R2原文、原生事件、Token隔离及官方现代/旧MCP客户端；见[开发验证](development.md)与[MCP接入](mcp.md)。真实Access登录、云端MCP域名和目标Agent客户端仍待部署验收。

此脚本验证Webhook复合归属、冻结内容和尝试记录约束；应用测试另行覆盖AES-GCM/HMAC、密钥轮换、租约和HTTP重试，见[Webhook说明](webhooks.md)。云端Email Routing、真实Webhook目标、发送unknown对账、投递状态、域名配置和D1云端迁移仍需端到端验收。本地验证不表示真实邮件已投递。

OAuth增量迁移新增7张表，保留原有22张表与已发布初始迁移；另见[单Worker配置检查记录](svelte-validation.md)。尚无可用部署按钮，[开源与部署设计](deployment.md)明确发布门槛。旧PostgreSQL/PGlite验证结果不适用于当前D1结构。
